| Описание                                     | Команда git bash                                                                     |
| -------------------------------------------- | ------------------------------------------------------------------------------------ |
| Создать и переключиться на ветку             | `git checkout -b имя`                                                                |
| Переключиться на ветку                       | `git checkout имя`                                                                   |
| Посмотреть список веток                      | `git branch`                                                                         |
| Добавить все изменения                       | `git add .`                                                                          |
| Сделать коммит                               | `git commit -m "сообщение"`                                                          |
| Отправить ветку на сервер                    | `git push -u origin имя ветки`                                                       |
| Слить ветку в текущую                        | `git merge имя`                                                                      |
| Удалить локальную ветку                      | `git branch -d имя`                                                                  |
| Удалить ветку на сервере                     | `git push origin --delete имя`                                                       |
| История коммитов                             | git log --pretty-format: "%ad %h %s" --date-format:"%Y-%m-%d"                        |
| получить изменения из удаленного репозитория | git pull origin                                                                      |
| поиск коммитов в ветке по заголовкам         | git log --grep=ВыражениеПоиска --pretty-format: "%ad %h %s" --date-format:"%Y-%m-%d" |
| переключиться на определенный коммит         | git chekout хэшКоммита или ИдХэша                                                    |
