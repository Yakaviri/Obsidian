
# Вариант А: Локальное слияние (без Pull Request)

## Переключитесь на main и обновите её:
	git checkout main
	git pull
## Слейте вашу ветку в main:
	git merge имя-ветки

## Отправьте обновлённый main на сервер:
	git push
## Удалить слитую ветку (опционально):

	git branch -d имя-ветки
	git push origin --delete имя-ветки

# Вариант Б: Через Pull Request (рекомендуется в командной работе)

## 1. Запушьте ветку: 
	git push -u origin имя-ветки
    
## 2. Зайдите на GitHub → откройте репозиторий → нажмите **Compare & pull request**
    
## 3. Создайте PR, дождитесь ревью и нажмите **Merge pull request**
    
## 4. После слияния на сервере обновите локальный main:
    

	git checkout main
	git pull
	git branch -d имя-ветки
