Шаг 1. создаем удаленный репозиторий в github

Шаг 2. Инициируем новый локальный Git репозиторий
		
		Git init
		
Шаг 3 Создаем .gitignore

	$ cat >> .gitignore << 'EOF'
	 .metadata/
	 .settings/
	 *.1CD
	 *.json
	 *.epf
	 *.erf
	 *.tmp
	 bin/
	 DumpFilesIndex.txt
	 ConfigDumpInfo.xml
	 src/Configuration/ParentConfigurations.bin
	src/Configuration/ParentConfigurations/**
	*.1CD
	*.CD
	 *.dt.bak
	EOF

Шаг 4 Добавляем в индекс файлы

	git add

Шаг 5. Подключаемся к Github по ssh:
	
	ssh -T git@github.com
Шаг 6 Делаем первый коммит

	git commit -m "Первый коммит"
	
Шаг 7 подключаемся к удаленному репозиторию

	git remote add origin git@github.com:Yakaviri/for1CLern.git

Шаг 8 отправляем первый коммит

	git push --set-upstream origin master

Шаг 9 Проверяем статус подключения

	 git remote -v
	 
Шаг 10 Создаем вертку main

	git branch -M main

Шаг 11 Передаем коммит из локального репозитория в удаленный в ветку main
	
	git push -u origin main
